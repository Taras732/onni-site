Зібрані ідеї для доведення сайту до фінального продукту. Пріоритезовано.

## 🔴 Must (перед публічним запуском)
- [ ] **Calendly-акаунт** Khristina + реальний `BOOKING_URL` (зараз placeholder)
- [ ] **Аанбеталінг / депозит проти no-show** — при бронюванні списується передоплата **70%** (універсальний слот: фікс **€35** = 70% мінімального манікюру; по типах: Manicure €35 / Pedicure €50 / Verlenging €75; фінал валідувати з Khristina). Зараховується у вартість. Скасування < 24–48 год або неявка → депозит не повертається. Механіка: **Calendly Standard + Stripe (iDEAL)**, рахунок Khristina. Підключати одразу після Calendly.

- [ ] **Справжній логотип** — якщо є файл, заміна типографічного wordmark (зараз «onni» із золотою «i»)
- [ ] Перевірити **точність цін** з Khristina (особливо чоловічий манікюр — зараз «op aanvraag»)
- [ ] Власний **домен** (напр. onni.nl / onninails.nl) замість github.io
